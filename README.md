# 实验室访客登记小程序

将 `../haplabentry-web` 的正式访客登记页面迁移为微信原生小程序，使用原生输入框、日期/选项选择器、复选框和 Canvas 2D，不依赖 Vue、Vant 或 npm 运行库。

## 运行

1. 使用微信开发者工具导入当前目录，使用项目现有 AppID。
2. 点击“编译”，进入“入场登记”。无需安装依赖或构建 npm。
3. 使用真机预览检查签名、键盘和完整提交流程。开发者工具跳过域名校验的设置不适用于正式发布。

建议使用稳定基础库 3.0.0 或以上；项目沿用开发者工具中的现有基础库选择。

## 接口与环境

`config.js` 根据 `wx.getAccountInfoSync().miniProgram.envVersion` 自动选择接口域名：

使用与网页相同的两个免登录接口：

- `GET /v1/haplabentry/public/visitors/options`：读取 `data.visit_periods`、`data.areas`、`data.nda_text`。
- `POST /v1/haplabentry/public/visitors`：请求体为 `{ data: { ... } }`；成功响应为 HTTP 200 和 `{ id: 正整数 }`。

签名从原生画布导出 PNG，转换为不带 data URL 前缀的纯 Base64，使用 `signature_base64` 提交。解码后最大 2 MiB，画布宽高不超过 4096 像素。读取完成后清理本次导出的临时图片。

与当前网页保持一致，前端仅要求姓名、承诺确认和手写签名；其他字段保留输入与长度限制，由后端决定是否接受。参考项目的接口文档较早，其中“全部必填”的说明与当前网页不一致，这里按正式页面实现迁移。

## 交互

- 姓名、手机号、证件号、单位、到访日期/时段、被访人、区域、事由。
- 日期默认使用本地当天，选项与承诺文本使用服务端原值。
- 选项加载失败可手动重试，加载成功前不能提交。
- 支持手写签名、清除重签、像素比适配。窗口宽度变化后需要重新签名；键盘改变窗口高度时保留签名。
- 提交期间锁定表单，阻止连点。成功后显示编号和“待审核”状态。
- 失败保留输入、承诺勾选和签名；网络异常或返回无效编号时提示联系前台核实，不自动重试。
- 表单、签名和登记结果仅保留在当前页面内存中；关闭页面后不恢复。不申请头像、昵称或微信登录。

## 检查

需要 Node.js 20 或以上，不需要 `npm install`：

```powershell
npm run check
npm test
```

前者检查 JavaScript、JSON、页面文件、事件绑定和测试目录的打包排除；后者使用内置测试框架和微信 API 替身验证接口格式、必填规则、签名大小、并发提交、异常响应和页面卸载。

已使用本机微信开发者工具的 WXML/WXSS 编译器进行编译检查。自动化检查不连接真实后端、不创建真实登记，仍需在开发者工具和真机中确认布局、签名触摸坐标、域名配置和后端提交。

## 目录

- `pages/index/`：登记表、手写签名及提交结果。
- `utils/api.js`：微信请求封装。
- `utils/registration.js`：表单、校验及接口字段映射。
- `utils/signature.js`：签名导出与临时文件清理。
- `config.js`：环境域名和请求超时。
- `tests/`：无需依赖的自动化检查，不进入小程序包。
